강의계획서와 수업자료를 넣어 두면 자료에 근거해 답하는 튜터가 됩니다. 설명 모드로 바로 알려 주거나, 힌트 모드로 되물으며 스스로 답에 이르게 돕습니다. API 키가 없으면 샘플 강의계획서와 샘플 답변으로 체험할 수 있어요.

교수님이 올린 강의계획서와 수업자료를 근거로 답하는 튜터예요. 성명·학과·학번을 입력하고 오른쪽 위 ⚙ 버튼에서 자기 API 키를 넣은 뒤 질문하세요. 대화를 마치면 제출 파일(JSON)을 저장해 제출합니다.

🙋 STUDENT INFO —— 제출 파일·저장 문서에 표시

키는 이 브라우저에만 저장되고 선택한 제공자 API로만 전송됩니다. 공용 PC에서는 키 저장을 끄세요.

키는 이 PC의 서버에만 저장되고 학생 브라우저로는 보내지 않습니다. 학생 질문 비용은 교수님 계정으로 청구됩니다.

💾 BACKUP —— 설정 내보내기 · 불러오기

⚠ 이 환경은 브라우저 저장이 막혀 있습니다(미리보기·사생활 보호 모드 등). 새로고침하면 입력이 사라지니 아래 설정 내보내기(JSON)로 보관하고 다음에 불러오기하세요.

강의 정보·참고자료·답변 규칙·히스토리를 JSON으로 저장합니다. API 키는 담지 않습니다.

챗봇 파일입니다. 본인의 API 키만 입력하세요. 키는 이 브라우저에만 저장됩니다.
